# Otwarte pytania do mentorów

Odpowiedź dopisz pod pytaniem i odhacz.

- [ ] Czy adapter demonstracyjny wystarczy zamiast prawdziwego drugiego kanału? Co uznają za „kanał równoważny”?
- [ ] Jak jury uruchomi rozwiązanie: publiczny URL czy Docker/lokalnie?
- [ ] Kto zapewnia klucze API (LLM, EUvsDisinfo, OCR) podczas oceny?
- [ ] Czy wolno wyszukiwać w internecie na żywo, czy tylko w zamkniętym korpusie?
- [ ] Jak liczone jest macro-F1: po twierdzeniu czy po zgłoszeniu? Czy „nie podlega weryfikacji” to osobna klasa?
- [ ] Czy powiadomienie moderatora (sprawy wysokiego ryzyka, powtarzające się pytania bez źródeł) jest wymagane w MVP, czy tylko premiowane?
- [ ] Czy zespoły dostaną jawny zestaw testowy? Kiedy?
- [ ] Jaka jest licencja danych EUvsDisinfo i czy można je przechowywać w korpusie?
- [ ] Termin i forma oddania projektu (godzina, platforma).
